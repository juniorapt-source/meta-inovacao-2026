Modo edição

Edite abaixo, gere o arquivo atualizado e substitua o correspondente na pasta data/ do repositório. Nada é salvo automaticamente nesta página.

Como publicar a mudança
1. Baixe o arquivo gerado e substitua o de mesmo nome em data/.
2. Valide: python3 tools/validar_dados.py.
3. Publique: git add data/ && git commit -m "atualiza dados" && git push — o Vercel redistribui sozinho.
